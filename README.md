**Push Agent** lets your visitors subscribe to browser notifications with one click, and lets you reach them on Chrome, Edge, Firefox, Opera and Safari, on desktop and mobile, even when your site isn't open.

- **Free plan:** up to 2,500 subscribers, unlimited notifications, no credit card
- **Standard Web Push:** no Firebase project or Google account needed
- **Scheduling and targeting** by country, device and browser
- **A/B testing**, and new blog posts sent automatically via RSS
- **WooCommerce order-status notifications** for your customers
- **REST API** to send notifications from your own code

### Repositories

| Repository | What it is |
|---|---|
| [pushagent-wordpress](https://github.com/pushagent/pushagent-wordpress) | WordPress plugin: web push plus WooCommerce order updates. Also on [WordPress.org](https://wordpress.org/plugins/push-agent/) |
| [pushagent-joomla](https://github.com/pushagent/pushagent-joomla) | Joomla system plugin (Joomla 3.8 to 6) |
| [pushagent-examples](https://github.com/pushagent/pushagent-examples) | Embed code for any website, and REST API examples in cURL, PHP, Node.js and Python |

### Get started

1. Create a free account at **[app.pushagent.net](https://app.pushagent.net)** and add your website.
2. Install the [WordPress](https://pushagent.net/docs/install-on-wordpress/) or [Joomla](https://pushagent.net/docs/how-to-install-push-agent-in-joomla/) plugin, or [add one line of code to any HTTPS site](https://pushagent.net/docs/add-push-notifications-to-any-website/).
3. Send your first notification.
